`microringlib` is a lightweight Python library for simulating microring resonators and related integrated-photonic circuits. It is designed to keep the physics visible: material indices, guided-mode quantities, coupling/loss, round-trip phase, resonator spectra, and system-level metrics are all represented explicitly.

The library is general and can be used with different photonic materials. The included publication demos focus on two platforms:

- **silicon photonics** as a baseline validation and teaching platform;
- **4H-SiC microring photonics** for resonance metrology, thermo-optic tuning, nonlinear optics, WDM filtering, quantum-link proxies, and FDTD handoff checks.

---

## What the library can model

| Area | What is included |
| --- | --- |
| Compact microring models | all-pass rings, add-drop rings, cascaded resonators, WDM banks |
| Transfer/scattering matrices | waveguides, couplers, phase shifters, MZIs, rings, Fabry-Perot cavities |
| Metrics | resonance search, linewidth, loaded Q, FSR, group delay, extinction ratio |
| Materials | constant, tabulated, functional, `refractiveindex`, and `PyOptik` material adapters |
| Optional FDE hooks | `modesolverpy`-based effective-index and group-index workflows |
| Optional FDTD hooks | MEEP/PyMEEP validation and calibration examples |
| Nonlinear / quantum demos | SHG proxies, SFWM toy models, pair-rate and CAR-style link budgets |


## Quick start

```python
import numpy as np
import microringlib as mrl

wl = np.linspace(1520e-9, 1580e-9, 2001)

layers = [
    mrl.Layer(material="Si core", thickness=220e-9, n=3.476, alpha=0.0),
    mrl.Layer(material="SiO2 cladding", thickness=2.0e-6, n=1.444, alpha=0.0),
]

ring = mrl.RingGeometry(radius=10e-6)
coupler = mrl.Coupler.from_power_coupling(0.08)

res = mrl.single_mrr_thru(
    wavelengths=wl,
    resonator=ring,
    layers=layers,
    t=coupler.t,
    kappa=coupler.kappa,
)

print("minimum through power:", res.power.min())
print("maximum through power:", res.power.max())
```

## Transfer/scattering matrix example

```python
import numpy as np
from microringlib import tmm

wl = np.linspace(1520e-9, 1580e-9, 2001)
neff = 2.42
alpha = tmm.dbcm_to_npm(2.0)

ring = tmm.ring_allpass_smatrix(
    wavelengths=wl,
    neff=neff,
    radius=10e-6,
    K=0.1,
    alpha_power=alpha,
)

assert ring.is_passive()
```

## Validation philosophy

`microringlib` is intended for interpretable modeling and early design exploration. It is not a replacement for final fabrication-calibrated PDK workflows or full 3D electromagnetic signoff.

Recommended wording when reporting results:

- **compact-model result** for TMM/S-matrix sweeps;
- **FDE-seeded result** when effective/group index comes from the mode solver;
- **FDTD hook / handoff result** when MEEP is used as a validation path;
- **proxy metric** when SHG, CAR, or process-corner figures are not experimentally calibrated.
